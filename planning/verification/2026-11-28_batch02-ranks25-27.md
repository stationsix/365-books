### Fixes applied
- Concept 2: "turn up bugs while the code is fresh" and "the risk of shipping rough code is outweighed by the speed of feedback" not found in the essay; replaced with the essay's own reason: frequent releases kept contributors "constantly stimulated and rewarded" by visible progress.
- Concept 3: Brooks's law line said bazaar contributors "work on separable tasks"; set to the essay's argument: the principle "is not repealed", debugging "is parallelizable" and needs little coordination, and "only within that small core group do we pay the full Brooksian overhead."
- Concept 5: "hostile forks" set to "forking projects"; the essay discourages forking in general, not only hostile forks.
- AI lens: "as The Magic Cauldron predicted" set to "described" (the essay describes the models; it does not forecast AI); "Raymond assumed that skilled contributors were the bottleneck" is not stated in the essays, so it is now marked as our reading.
